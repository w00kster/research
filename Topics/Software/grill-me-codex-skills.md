## Overview

Grill-Me-Codex implements skill-based interrogation system that questions users about their work plans. Evolved from [[Matt Pocock Skills]] (which went semi-viral) to create more sophisticated planning and task decomposition.

## Problem/Motivation

Interested in skill-based work planning and AI-driven task interrogation. Grill-Me-Codex represents approach to decomposing complex work into structured steps through conversational questioning.

## Key Concepts

**Skills-Based Interrogation**: Ask targeted questions to understand work scope, requirements, and edge cases.

- Work plan interrogation
- Requirement gathering
- Edge case identification
- Task decomposition
- Specification generation

## Relationship to Matt Pocock

- [[Matt Pocock Skills]] - Original concept that gained traction
- Grill-Me-Codex - Evolution with more sophisticated questioning
- Both focus on skill-based work planning

## How It Works

1. **Plan Understanding**: AI interrogates user about intended work
2. **Scope Clarification**: Questions about requirements and constraints
3. **Edge Cases**: Explores potential problems and scenarios
4. **Specification**: Generates detailed work specification
5. **Decomposition**: Breaks down into concrete tasks
