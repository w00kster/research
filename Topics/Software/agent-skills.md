# Agent Skills - Framework for AI Agent Capabilities

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: ai, agents, skills, framework, automation

## Overview
A framework for defining, sharing, and composing capabilities (skills) for AI agents. Enables modular development of agent behaviors that can be combined and reused across different agent implementations and use cases.

## Key Points
- **Modular Design**: Break agent capabilities into reusable skill components
- **Skill Discovery**: Registry and marketplace for sharing agent skills
- **Composition**: Combine multiple skills to create complex agent behaviors
- **Standard Interface**: Consistent way to invoke and manage skills across agents
- **Versioning**: Skills can be versioned and updated independently
