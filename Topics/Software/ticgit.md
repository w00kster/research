# TicGit - Git-Based Wiki and Ticket System

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: git, wiki, ticketing, version-control, collaboration

## Overview
A distributed wiki and ticket tracking system that uses Git as its backend. Combines version control with collaborative documentation and issue management in a single tools.

## Key Points
- **Git Backend**: All data stored in Git repositories for version control
- **Distributed**: Works offline and syncs when connectivity is available
- **Wiki Features**: Collaborative documentation with markup support
- **Ticket Tracking**: Issue management integrated with documentation
- **Command Line**: Primary interface via git commands
