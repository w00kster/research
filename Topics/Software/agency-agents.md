# Agency Agents - Framework for AI Agent Organizations

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: ai, agents, agency, organization, framework

## Overview
A framework for creating and managing organizations of AI agents that work together to accomplish complex goals. Provides structures for agent communication, task delegation, and collective decision-making within agent-based systems.

## Key Points
- **Agent Organizations**: Structure for groups of agents working toward common objectives
- **Communication Protocols**: Standardized ways for agents to exchange information
- **Task Delegation**: Systems for assigning and tracking work across agent teams
- **Collective Intelligence**: Mechanisms for group decision-making and problem-solving
- **Hierarchy Support**: Ability to create agent hierarchies with different roles and responsibilities
