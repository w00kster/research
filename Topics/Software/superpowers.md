# SuperPowers - Open Source Game Engine

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: game-engine, graphics, 2d-3d, game-development, open-source

## Overview
An open source game engine for creating 2D and 3D games. Provides a comprehensive framework for game development including rendering, physics, audio, input handling, and scene management with a focus on accessibility and flexibility.

## Key Points
- **Open Source**: Free to use, modify, and distribute under permissive license
- **Cross-Platform**: Deploy games to web, desktop, and mobile platforms
- **Component-Based**: Entity-component-system architecture for flexible game objects
- **Live Reloading**: See changes instantly during development without full recompilation
- **TypeScript**: Written in TypeScript for strong typing and modern JavaScript features
