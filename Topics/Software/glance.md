# Glance - Self-Hosted Dashboard

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: dashboard, monitoring, self-hosted, visualization, widgets

## Overview
Glance is a self-hosted dashboard application that allows users to create personalized pages with various widgets and information displays. Combines multiple data sources into a single, customizable interface for monitoring and visualization.

## Key Points
- **Self-Hosted**: Run on your own infrastructure for complete control and privacy
- **Customizable Layouts**: Arrange widgets and information blocks as desired
- **Multiple Data Sources**: Integrate with various APIs, databases, and file systems
- **Widget System**: Modular components for displaying different types of information
- **Real-Time Updates**: Support for live data updating without manual refresh
