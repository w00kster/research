## Problem/Motivation

Traditional web automation and scraping tools require detailed knowledge of HTML/CSS selectors, XPath, and browser automation APIs. This creates a steep barrier to entry for non-technical users and makes scripts brittle when websites change. An LLM-powered approach could make web automation more accessible and resilient to UI changes by understanding the semantic intent behind automation tasks rather than relying on brittle selectors.
