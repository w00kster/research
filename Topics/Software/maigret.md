# Maigret - OSINT (Open Source Intelligence) Tool

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: osint, intelligence, investigation, username, social-media

## Overview
Maigret is an OSINT (Open Source Intelligence) tool for collecting information about individuals from public sources. It specializes in finding usernames across hundreds of websites and social media platforms to help investigate online identities and digital footprints.

## Key Points
- **Username Hunting**: Search for specific usernames across 300+ websites
- **Profile Aggregation**: Collect public profile information from multiple sources
- **Identity Investigation**: Build comprehensive pictures of online identities
- **Data Enrichment**: Enhance existing information with additional context from social platforms
- **Automated Research**: Perform reconnaissance that would take hours manually in minutes
