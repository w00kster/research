# Plannotator - Planning and Annotation Tool

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: planning, annotation, diagrams, collaboration, productivity

## Overview
A collaborative tool for creating diagrams, flowcharts, and annotated plans. Combines planning capabilities with annotation features to help teams visualize and document processes, architectures, and ideas.

## Key Points
- **Diagram Creation**: Flowcharts, mind maps, and organizational charts
- **Annotation Features**: Add notes, comments, and explanations to visual elements
- **Real-time Collaboration**: Multiple users can work on the same document simultaneously
- **Export Options**: Export to various formats (PNG, SVG, PDF) for sharing and publishing
- **Template Library**: Pre-built templates for common planning scenarios
