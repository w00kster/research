# Open Slide - Open Source Presentation Software

**Category**: Software
**Added**: 2026-08-06
**Status**: Active
**Tags**: presentation, slides, open-source, productivity

## Overview
Open source software for creating, editing, and presenting slideshows and presentations. Provides a free alternative to proprietary presentation tools with collaborative features and cross-platform compatibility.

## Key Points
- **Open Source**: Free to use, modify, and distribute
- **Cross-Platform**: Works on Windows, macOS, and Linux
- **Collaboration**: Supports real-time collaborative editing
- **Format Support**: Compatible with common presentation formats (PPT, ODP, PDF)
