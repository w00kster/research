# Physical Volume Control & Macro Keyboard Project

**Category**: Hardware  
**Added**: 2026-06-12  
**Status**: Backlog  
**Tags**: hardware-project, audio-control, macro-keyboard, diy, input-device, audio-faders

## Overview

Project to build a custom physical volume control device with audio faders for application-level control and macro keyboard with 16+ programmable keys. Enables tactile, application-aware audio mixing and hotkey management.

## Problem/Motivation

Interested in building custom hardware input device for better audio mixing and workflow automation. Particularly interested in audio faders for granular per-application volume control. Has considered this project for a while and wants to explore implementation approaches.

## Key Interest Areas

- **Physical Faders**: Application-level audio mixing with tactile feedback
- **Programmable Keys**: Macro keyboard with 16+ customizable keys
- **Integration**: Could integrate with homelab for media server control or application automation
- **Extensibility**: Foundation for expanding with additional controls
